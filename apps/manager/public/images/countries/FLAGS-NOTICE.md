# Country flag assets

SVG flags come from [mledoze/countries](https://github.com/mledoze/countries/tree/fa4f62182d19ff4f8b325cde6387c9cd9d80955a/data), commit `fa4f62182d19ff4f8b325cde6387c9cd9d80955a`.

Flags are explicitly excluded from the dataset's ODbL license. Upstream refers to [Wikipedia: Copyright on emblems](https://en.wikipedia.org/wiki/Wikipedia:Copyright_on_emblems); copyright and national-symbol usage restrictions can vary by artwork and jurisdiction. This bundle does not claim a single license or blanket public-domain status for all flag artwork.

SVG comments and metadata are retained. External DOCTYPE declarations are removed, and the bundler rejects active content and non-local resource references. SVGs are served as separate images, never injected as HTML.

Files use canonical country slugs, for example `france.svg` or `united-states.svg`. These assets are identifying country flags, not newly created brand marks. Country metadata remains covered by ODbL 1.0; these flag assets do not.
